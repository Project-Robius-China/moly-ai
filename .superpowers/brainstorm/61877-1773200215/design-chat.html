2B. MolyKit Action Buttons (New Widget)

Generic, reusable — any BotClient can return action buttons

AITK Protocol Extension
// aitk::protocol::MessageContent
pub struct MessageContent {
  // ... existing fields ...
  pub text: String,
  pub citations: Vec<String>,
  // NEW:
  pub action_buttons: Vec<ActionButton>,
}

pub struct ActionButton {
  pub label: String,
  pub action: String,
  pub style: ButtonStyle,
}

pub enum ButtonStyle {
  Primary,
  Secondary,
  Subtle,
}
Rendering Pipeline
Data Flow:
BotFatherClient::send()
  ↓ yields MessageContent with action_buttons

StandardMessageContent
  ↓ detects non-empty action_buttons
  ↓ renders ActionButtonGroup below text

ActionButtonGroup (new widget)
  ↓ user clicks "Create a Bot"
  ↓ dispatches ActionButtonClicked { action: "/newbot" }

Chat widget
  ↓ handles action, injects "/newbot" as user message
  ↓ sends to BotFatherClient for processing
